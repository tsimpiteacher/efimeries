# Εφημερίες

Εφαρμογή που διαβάζει το εβδομαδιαίο πρόγραμμα (Excel) και φτιάχνει το Word με τις εφημερίες.

## Χρήση
1. Άνοιξε το `index.html` (ή τη σελίδα GitHub Pages του repo).
2. Ανέβασε το πρόγραμμα `.xlsx`, ρύθμισε εξαιρέσεις / μάχιμους / όρια ημερών και κατέβασε το `Εφημερίες_<ημερομηνία>.docx`.
3. Πάτα «Αποθήκευση επεξεργασίας» για να κρατήσεις το `Εφημερίες_<ημερομηνία>.json` (φορτώνεται αργότερα για διόρθωση).

## Στατιστικά
Κάθε εβδομάδα κατέβασε το `Στατιστικά_<ημερομηνία>.json` και ανέβασέ το στον φάκελο `stats/` (Add file → Upload files).
Την επόμενη εβδομάδα φόρτωσε το πιο πρόσφατο αρχείο στατιστικών στην εφαρμογή, ώστε η ισότητα εφημεριών να συνεχίζεται από εβδομάδα σε εβδομάδα.

## Προσοχή
Μην ανεβάζεις κωδικούς/tokens. Αν το repo είναι δημόσιο, τα αρχεία στατιστικών με ονόματα συναδέλφων θα είναι ορατά σε όλους — προτίμησε **Private** repo.
